# Ascend 上的树共享注意力

本项目完成了共享 KV 的树形调度、Triton Ascend 矩阵注意力内核和公开 Qwen3-4B 解码集成。128 个请求各有 8192 token 上下文、其中 8128 token 共享时，动态分组的常驻执行为 2.523 ms，厂商最快布局为 2.839 ms，达到 1.126 倍加速。81 种独立评价树形态上，相对逐请求树内核的几何平均加速为 1.315 倍。所有主实验均保留三次独立进程重复和原始记录。

## 调度与执行

压缩前缀树保存公共上下文，每个节点记录自己的 KV 位置和经过该节点的请求。调度器可以让这些请求共同处理公共上下文，也可以把上下文推入部分子分支。动态规划按已经分离的请求数量保存候选状态，比较当前节点与后续子树的总成本。贪心基线逐个子节点比较局部 SplitQ/SplitK 成本，固定基线则直接按树节点共享。

成本计算包含 Cube 查询行填充、上下文切分、物理 KV 连续性、读写与分段合并。逻辑相邻但物理位置不连续的 KV 会分开读取。独立校准选出小查询组使用 16×128、大查询组使用 64×64 的矩阵块。

每段注意力保存归一化输出和 log-sum-exp，合并时恢复全局 softmax 权重。每个请求仍然对自己的完整上下文计算注意力。重复请求、内部节点结束的请求、不等长分支和深树由同一语义处理。

Qwen3 集成保留投影、Q/K 归一化、旋转位置编码、MLP 和词表输出。预填充后，公共 KV 只保存一份。两种规划模式均为每个请求预留连续的生成尾部；缓存模式在解码时更新尾部有效长度，提示词分组与临时缓冲区跨层、跨步复用。

## 树形态与实际成本

六种代表性形态包括无共享、宽树、不等长分支、深树，以及请求数和上下文长度完全相同的长共享、长无共享树。厂商基线同时测量 BNSD 与 BSH，输入布局从同一共享 KV 池构造；转换与常驻执行分别记录。

| 128 请求 × 8192 token | 动态分组常驻执行 | 最快厂商常驻执行 |
|---|---:|---:|
| 共享 8128 token | 2.523 ms | 2.839 ms |
| 无共享 | 38.984 ms | 2.839 ms |

共享树只需 256 个物理计算任务，无共享树需要 2048 个。私有请求仅贡献四行 grouped-query 查询，却需要填充到 16 行 Cube 块；任务数量、填充和合并会抵消有限的复用收益。其余四个较小形态均有厂商布局快于当前树内核。

准备成本同样影响选择。长共享树的固定分组总成本为 7.35 ms，动态规划为 78.73 ms，最佳厂商布局为 35.55 ms。这些总数包含布局、规划、元数据和一次注意力执行。动态规划与固定分组的常驻内核接近，但初始规划代价高。

完整 81 树网格显示，共享根越长、请求越多，共享计算越有利。4 请求、32 token 公共根时，相对逐请求的几何平均加速为 1.026 倍；24 请求、768 token 公共根时为 1.855 倍。全部形态范围为 0.879–2.641 倍。动态规划在 58/81 棵树上改变固定分组，但相对逐子节点贪心仅在一棵树上降低约 0.04% 的估计成本。相对 fixed/greedy 的常驻执行几何平均比值为 1.008/1.005，不能支持普遍的动态规划优势。

## 复用计划与真实模型

32 请求、1024 token 共享提示、每请求 64 token 私有提示的 16 步实验计入真实计划更新和初始规划摊销：

| 策略 | 每步重建 | 缓存计划 |
|---|---:|---:|
| 固定分组 | 1.400 ms | 0.536 ms |
| 贪心 | 3.126 ms | 0.564 ms |
| 动态规划 | 3.896 ms | 0.606 ms |

动态规划路径因此达到 6.43 倍加速，固定分组缓存仍更快。这个实验把复用提示计划的收益与初次选择计划的算法分开评价。

公开 Qwen3-4B 在四类 SQuAD 文本负载上运行，每类 8 请求、每请求生成 16 token，包含文档问答、多轮历史、多分支续写和无共享上下文。两种规划模式各有三个独立进程，全部方法和波动范围见英文报告。

| 缓存计划负载 | 逐请求解码总时间 | 动态分组解码总时间 | 动态分组完整生成时间 |
|---|---:|---:|---:|
| 文档问答 | 526.0 ms | 508.7 ms | 1173.8 ms |
| 多轮历史 | 525.5 ms | 528.9 ms | 1199.0 ms |
| 多分支续写 | 474.6 ms | 496.2 ms | 844.1 ms |
| 无共享 | 481.5 ms | 482.9 ms | 820.7 ms |

文档问答的完整解码时间降低 3.3%，计入预填充后完整生成降低 1.5%。真实模型中，投影、MLP 和预填充占据大部分时间，单独算子与计划更新的收益因此被稀释。

## 正确性与生成差异

七项 CPU 测试、32 项 NPU 算子比较、81 树 × 4 策略 × 3 进程的 972 项完整注意力比较全部通过。随机小型 Qwen3 的缓存与重建路径各通过 12 项完整序列 logits 比较。

预训练模型完成 1224 项同 Q/K/V 逐层验证，分别对照独立 FP32 完整注意力和厂商融合算子。树内核最大相对 L2 误差为 0.218%，厂商为 0.245%。短上下文和文档检查中，树路径相对完整序列 BF16 的最大 logit 相对 L2 为 2.692%；标准 Hugging Face cached/full 路径自身差异最大为 2.868%，这些检查的首选 token 均一致。

正式生成中，文档问答、多轮历史和无共享负载的策略 token 一致率为 100%，多分支续写为 89.84%。首次分叉位于第 10 个生成 token、两个请求上。共同历史下，逐请求路径的 top-2 BF16 logits 完全并列，固定分组的间距分别为 0.125 和 0.25，其选择与完整序列路径在这两个请求上相同。该历史下的 72 层独立 FP32 注意力比较全部通过；近并列 logits 的数值差异经自回归反馈扩展为不同续写。原始历史、top-2 logits 和逐层结果均已保存。

## 限制

成本模型的带宽和计算常数是解析估计，矩阵块有独立校准。当前实现支持单卡、固定请求批次、完整注意力和每请求单 token 解码，预填充沿用原模型路径。四组短生成实验验证实现和运行成本，不代表全面模型质量评价。BF16 数值路径可以改变近并列 token 的选择。合成测试峰值内存包含驻留参考布局，不能作为生产模型显存节省结论；本机结果不外推到多机或其他加速器。
